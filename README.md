## Featured Work

### [Telegram AI Lead Bot](https://github.com/imnikkl/telegram-bot)
An automated assistant for real estate operating inside Telegram. Combines Google Gemini for conversational lead qualification with an automated matching engine to pair buyer criteria with relevant property listings.
> **Technologies:** Python, Google Gemini, Telegram Bot API

### [n8n Advanced Scraping](https://github.com/imnikkl/n8nscrap)
A headless data extraction pipeline coordinating n8n workflow automations, Playwright for dynamic browser scraping, PostgreSQL for storage, and a GraphQL querying layer for structured exports.
> **Technologies:** n8n, Playwright, PostgreSQL, GraphQL

### [GPT Watch](https://github.com/imnikkl/gptwatch)
A native Android mobile application built with Kotlin, interfacing with low-latency LLM providers (Groq and DeepSeek) to deliver rapid AI streaming responses on mobile devices.
> **Technologies:** Kotlin, Android SDK, Groq, DeepSeek API

### [Python CV Apps](https://github.com/imnikkl/pythonAPPS)
Real-time computer vision experiments leveraging Google MediaPipe's Hand Landmarker pipeline for hand tracking, landmark detection, and gesture-driven actions.
> **Technologies:** Python, MediaPipe, OpenCV
